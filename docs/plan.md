# 마녀의 출석부 계획서

- 작성일: 2026-11-15
- 수정일: 2026-11-15 (확인 사항 답변 반영: 횟수로만 수강료, 출석·결석만, 공개 저장소, 폴드7·8 대응, 학원 로고 그림 중심 디자인)
- 상태: 확정. 2026-11-15 2차 개편으로 구조가 바뀌었습니다 — **학생·반 대신 '수업'(1:1 레슨 / 그룹 수업)**, 기본 규칙은 설정에서 한 번에, 폴드 전용 배치 대신 넓은 화면 일반. 바뀐 내용은 [decisions.md](decisions.md) 51~64가 이 계획서보다 우선합니다.

## 1. 목표

**마녀의 우쿨렐레 & 칼림바** 학원의 선생님이 학생들의 **출결**, **수강료 납부**, **보강 일정**을 한 앱에서 관리합니다.

- 학원노트가 "학부모 → 여러 학원"이었다면, 이 앱은 **"선생님 → 여러 학생"**입니다. 학생 수는 10~60명 정도를 기준으로 합니다.
- **1:1 레슨과 여러 명이 듣는 반 수업**을 모두 다룹니다. 1:1 레슨은 학생이 한 명인 반입니다.
- 수강료는 **횟수로만** 받습니다. (예: 8회 16만 원) 달에 수업이 다섯 번 있어도 따로 할 일이 없습니다.
- 서버 없이 데이터는 **기기에만 저장**하고, 백업 파일로 다른 기기와 주고받습니다.
- 기본은 휴대폰이지만 **폴드(갤럭시 Z 폴드7, 폴드8), 태블릿, PC**에서도 불편 없이 씁니다. (3장)
- **웹 버전을 먼저** 만듭니다. APK는 웹 버전이 안정된 뒤에 Capacitor로 감쌉니다. (학원노트와 같은 방식)
- 화면은 **학원 로고 그림(마녀, 고양이)**을 주인공으로 디자인합니다. (4장)

## 2. 주요 기능

### ① 학생

| 항목 | 예시 | 필수 |
|---|---|---|
| 이름, 표시 색 | 김하준 / 호박색 | 이름만 필수 |
| 학교·학년 | 한빛초 3학년, 성인 | 선택 |
| 학생 전화번호 | 010-… | 선택 |
| 보호자 (관계, 전화번호) | 어머니 010-… | 선택, 여러 명 |
| 등록한 날, 메모 | 2026-11-15 / 악기 대여 중 | 등록한 날 기본값 오늘 |

- 목록은 이름 순서이고, **이름·학교로 찾기**, 상태(다니는 중 / 쉬는 중 / 그만둠)로 걸러 보기를 지원합니다.
- 연락처가 있으면 학생 화면에서 **전화·문자 단추**를 바로 누릅니다. (폰의 전화·문자 앱이 열림)
- **쉬기(휴원)**: 쉬는 동안 수업 명단에서 빠지고 남은 횟수는 그대로 남습니다. **그만두기**: 지난 기록은 남고 이후 수업만 없어집니다.

### ② 반

| 항목 | 예시 |
|---|---|
| 반 이름, 과목, 표시 색, 장소 | 우쿨렐레 초급반 / 우쿨렐레 / 1교실 |
| 수업 요일과 시간 | 월·수 16:00~16:50 (요일마다 시간이 달라도 됨) |
| 수강료 | 8회마다 16만 원 |
| 결석한 수업을 세는 방법 | 보강하면 안 세고, 안 하면 셈 (세 가지 중 선택) |
| 보강 규칙 | 결석·휴강 보강, 빠진 날부터 14일 안 |
| 학생 | 반에 들어온 날, 나간 날, 듣는 요일, 학생만의 수강료 |

- 주 1회든 주 2회든 요일만 고르면 됩니다. 주 2회 반에서 **한 요일만 듣는 학생**은 그 학생의 '듣는 요일'로 정합니다.
- 학기 중에 요일·시간이 바뀌면 **언제부터 바뀌는지**를 넣습니다. 그 전의 수업과 출결은 그대로 남습니다.
- 한 반은 한 요일에 수업이 하나입니다. 하루에 두 번 수업하면 반을 하나 더 만듭니다.

### ③ 출결 (핵심)

- 수업 카드를 누르면 **그 자리에서 펼쳐져** 학생마다 **출석 / 결석**을 누릅니다. (지각·조퇴는 따로 적지 않음)
- **누르는 즉시 저장**합니다. 저장 단추가 없고, 같은 단추를 한 번 더 누르면 '체크 전'으로 돌아갑니다.
- **[모두 출석]** 으로 한 번에 채우고, 빠진 학생만 결석으로 바꿉니다.
- 결석이면 사유를 적는 칸과 보강 단추가 생깁니다. 선생님 사정으로 쉬면 **휴강**으로 적습니다.
- 출결을 안 적고 지나간 수업은 '체크 전'으로 남고, 홈에서 알려줍니다.

| 보기 | 내용 |
|---|---|
| 홈 | 오늘 수업, 출결을 안 적은 지난 수업 |
| 출결 (월) | 달력 칸에 반 색 칩, 고른 날의 수업 |
| 출결 (주, 일) | 요일별·하루 수업 목록 |
| 반의 출석부 표 | 학생 × 날짜 표. 칸을 누르면 출석 → 결석 → 지움 |
| 학생 화면 | 이번 달 출석·결석·보강·체크 전 횟수 |

### ④ 보강

결석이나 휴강을 적으면 반 규칙에 따라 **보강이 자동으로 생깁니다.**

- 보강 기한: 빠진 날부터 N일 안 / 같은 달 안 / 다음 달 말까지 / 기한 없음
- 날짜를 잡는 방법 두 가지
  1. **따로 시간 잡기**: 날짜와 시각을 정합니다. 같은 시간으로 잡은 학생들은 '보강 수업' 하나로 묶여 보입니다.
  2. **다른 수업에 같이 듣기**: 그날의 다른 수업을 고르면 그 수업 출석부에 '보강' 꼬리표로 올라갑니다.
- 그날 다른 수업과 시간이 겹치거나 기한을 넘기면 알려주기만 하고 막지는 않습니다.
- **휴강 보강은 반 학생들을 한 번에** 같은 날로 잡을 수 있습니다.
- 상태: 대기 → 예정 → 완료, 또는 보강 안 함, 기한 지남

### ⑤ 납부 (횟수로만)

횟수권과 같은 방식입니다.

1. 수강료를 받으면 그 횟수만큼 **남은 횟수**가 채워집니다.
2. 수업을 하면 한 번씩 줄어듭니다.
3. 남은 횟수를 다 쓰면, **그다음 수업 날이 새 수강료를 받을 날**입니다.

- 달에 수업이 다섯 번 있어도 다섯 번째 수업이 다음 묶음의 첫 회가 될 뿐입니다.
- 받을 날이 지났으면 '받을 날 지남'으로, 일주일 안이면 '받을 예정'으로 홈과 납부 화면에 올라옵니다.
- 받을 날 전에 **미리 받거나 여러 묶음을 한 번에** 받을 수 있습니다. (횟수를 바꾸면 금액도 같은 비율로)
- 학생마다 **수강료를 다르게** 정할 수 있고(형제 할인 등), 전부터 다니던 학생은 **남아 있던 횟수**를 적어 이어서 셉니다.
- **교재비, 특강비** 같은 추가 항목을 따로 청구합니다.
- 달마다 받은 돈 합계와 내역을 봅니다.

**결석한 수업을 세는 방법** (반마다 선택)

| 방법 | 동작 |
|---|---|
| 보강하면 안 세고, 안 하면 셈 (기본) | 보강을 하면 보강한 날에 한 번, 보강을 안 하거나 기한이 지나면 결석한 날에 셈 |
| 결석해도 셈 | 결석한 날에 셈. 보강을 해도 더 늘지 않음 |
| 결석은 안 셈 | 남은 횟수가 그대로. 보강을 하면 그날 셈 |

휴강은 어느 방법이든 세지 않고, 휴강 보강을 하면 그날 셉니다.

### ⑥ 홈

- 큰 그림과 함께 오늘 날짜와 오늘 수업을 한 문장으로 ("오늘 수업은 3개예요, 16:00에 우쿨렐레 초급반부터 시작해요")
- 오늘 수업 (누르면 바로 출석 체크), 출결을 안 적은 지난 수업
- 남은 보강 (급한 순서), 받을 돈 (받을 날이 지났거나 일주일 안)

### ⑦ 백업과 복원

- 모든 데이터를 파일 하나(`.json`)로 내보내고 가져옵니다. (덮어쓰기 / 합치기)
- 백업 파일에는 학생 이름과 연락처가 들어 있어 **개인정보 파일**로 다룹니다. 앱 안에 안내합니다.

### ⑧ 나중에 (이번 범위 밖)

- 보호자 안내 문구 만들기 (결석, 보강 일정, 납부 안내를 복사하거나 문자 앱으로)
- 출석부 표 A4 인쇄
- APK로 감싸기, 실제 폰 알림 (수업 전, 받을 날, 보강 전날), 앱 잠금(PIN)
- 여러 선생님이 같은 데이터를 쓰는 공유 (학원노트의 가족 공유 방식)
- 수업 후에 받는 방식(후불), 일부만 받은 납부

## 3. 화면 대응 (휴대폰, 폴드, 태블릿, PC)

### 3-1. 배치 규칙

기기 종류가 아니라 **화면 모양과 그 자리의 너비**로 배치를 정합니다. 배치는 모두 CSS로만 바꾸므로, 화면 크기가 바뀌어도 화면을 다시 만들지 않습니다.

| 정하는 것 | 규칙 |
|---|---|
| 메뉴 위치 | 세로 화면은 **아래쪽 탭**, 가로 화면(가로가 세로의 1.2배 이상이고 600px 이상)은 **왼쪽 메뉴**. 1024px 이상은 늘 왼쪽 |
| 칸 수 | 그 자리의 너비가 약 680px(40rem) 이상이면 **두 칸**, 아니면 한 칸 |
| 두 칸의 경계 | 화면 **한가운데**. 폴드의 접힌 선이 칸 사이 빈자리에 옵니다. PC는 목록 칸을 고정 너비로 |

### 3-2. 갤럭시 Z 폴드7과 폴드8

두 기기는 화면 모양이 서로 다릅니다. (크기는 CSS 픽셀, 기기의 화면 확대 설정에 따라 조금 달라짐)

| | 폴드7 (2025) | 폴드8 (2026) |
|---|---|---|
| 접은 화면 | 6.5형 1080×2520, **길쭉함(21:9)**. 약 384~412 × 880~960 | 5.5형 1248×1972, **짧고 넓음(10:16)**. 약 416 × 657 |
| 펼친 화면 | 8.0형 1968×2184, **거의 정사각형**. 약 750 × 832 | 7.6형 2448×1848, **가로로 넓음(4:3)**. 약 933 × 704 |
| 접었을 때 배치 | 일반 휴대폰과 같음 | 높이가 낮아 한 화면에 보이는 양이 적음. 고정 막대를 줄임 |
| 펼쳤을 때 배치 | **아래쪽 메뉴 + 반씩 두 칸** | **왼쪽 메뉴 + 두 칸** |

- 폴드7의 펼친 화면은 정사각형에 가까워, 왼쪽 메뉴를 두면 두 칸으로 나눌 너비가 모자랍니다. 그래서 아래쪽 메뉴를 그대로 두고 화면을 반씩 나눕니다.
- 폴드8 울트라는 폴드7과 같은 모양(21:9 / 10:9)이라 폴드7과 같게 동작합니다.

**접고 펼 때**

- 적던 내용(학생 정보, 납부 금액, 메모), 보던 학생이나 반, 열려 있던 창, 펼쳐 둔 출석부가 **그대로 남습니다.**
- 목록과 자세히 화면은 같은 주소를 씁니다. 접은 화면에서 학생을 보다가 펴면 왼쪽에 목록이 나타나고, 다시 접으면 그 학생만 보입니다.
- 출결은 누르는 즉시 저장하므로 접는 순간에 잃어버릴 것이 없습니다.

### 3-3. 확인 방법

화면 테스트(Playwright + PC의 Edge)를 아래 크기에서 자동으로 돌립니다.

| 이름 | 크기 | 돌리는 테스트 |
|---|---|---|
| 좁은-폰 | 320×640 | 배치 |
| 폰-세로 | 360×780 | 배치 + 기능 + 접고 펴기 |
| 폴드7-접음 | 412×880 | 배치 |
| 폴드8-접음 | 416×580 | 배치 |
| 폴드7-펼침 | 750×790 | 배치 + 기능 |
| 폴드8-펼침 | 932×620 | 배치 |
| 폰-가로 | 780×360 | 배치 |
| 태블릿-세로 | 800×1280 | 배치 |
| PC | 1366×768 | 배치 + 기능 |

- **배치 테스트**: 모든 화면이 옆으로 넘치지 않는지, 메뉴 위치와 칸 수가 맞는지, 두 칸의 경계가 화면 한가운데인지, 창이 화면 안에 들어오는지
- **접고 펴기 테스트**: 입력하는 도중에 화면 크기를 접은 크기 ↔ 펼친 크기로 바꿔 내용이 남는지 (폴드7, 폴드8 각각)
- 실제 기기에서는 폴드를 접고 펴 보며 확인이 필요합니다.

### 3-4. 삼성 인터넷 주의점 (학원노트에서 겪은 것)

- **항상 밝은 화면**(`color-scheme: only light`)으로 강제 다크 모드를 막습니다.
- 글자 크기는 rem 단위라 브라우저 글자 크기를 키우면 화면 전체가 함께 커집니다.
- 주소창이 숨고 나타나며 높이가 바뀌어도(`100dvh`) 아래쪽 메뉴가 가려지지 않게 합니다.
- 날짜는 기기마다 모양이 다른 기본 입력창 대신 앱의 달력으로 고릅니다.

- 학생과 반의 표시 색은 그림과 어울리는 여덟 가지(호박, 자두, 올리브, 청록, 하늘, 분홍, 벽돌, 밤색)입니다.

## 5. 기술 구성

학원노트와 같은 구성입니다. 이미 설치된 도구와 검증된 코드를 그대로 씁니다.

| 구분 | 선택 | 이유 |
|---|---|---|
| 앱 방식 | **React + TypeScript + Vite** | 학원노트와 같음. 같은 코드로 나중에 APK도 만듭니다. |
| 화면 주소 | react-router **HashRouter** | GitHub Pages나 APK에서 그대로 동작 |
| 저장 | **IndexedDB** (idb), 저장소 계층 하나로 모음 | 화면은 저장소 계층만 거칩니다. |
| 테스트 | vitest(계산), **Playwright + Edge**(화면) | 학원노트와 같음 |
| 폰에서 열어 보기 | **GitHub Pages** (공개 저장소) | 주소만 열면 됩니다. 데이터는 기기에만 저장되고 코드만 공개됩니다. |
| APK (나중에) | Capacitor | 학원노트에서 만든 빌드 스크립트와 `90_Tools/`의 JDK·SDK 재사용 |

**개인정보 주의**

- 학생 이름과 전화번호는 **기기에만** 저장하고 서버로 보내지 않습니다.
- 예시 데이터와 테스트는 지어낸 이름과 `010-0000-00xx` 번호만 씁니다. 실제 학생 정보는 저장소에 절대 넣지 않습니다.
- 웹 단계는 브라우저의 사이트 데이터를 지우면 기록도 사라집니다. 백업 파일을 자주 내보내야 합니다.

## 6. 데이터 구조 (요약)

- **학생**: 이름, 색, 학교·학년, 전화번호, 보호자(관계·전화번호), 등록한 날, 쉰 기간, 그만둔 날, 메모
- **반**: 이름, 과목, 색, 장소, 시작일, 일정(기간별 요일·시간), 수강료(횟수·금액), 결석 세는 방법, 보강 규칙
- **수강**: 반, 학생, 시작한 날, 나간 날, 듣는 요일, 학생만의 수강료, 넣을 때 남아 있던 횟수
- **수업 기록**: 반, 날짜, 휴강 여부, 메모 — 수업 날은 반 일정에서 계산하고, 적을 것이 있을 때만 저장
- **출결**: 반, 학생, 날짜, 출석/결석, 사유 — 체크한 것만 저장
- **보강**: 반, 학생, 빠진 날, 이유(결석/휴강), 기한, 예정일과 시각, 같이 듣는 반, 상태
- **납부**: 학생, 반, 종류(수강료/교재비/특강비/기타), 금액, 채워지는 횟수, 받기로 한 날, 받은 날, 방법, 메모
